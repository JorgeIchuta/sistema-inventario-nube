# Template de Inventario Cloud

Prototipo visual y navegable creado con HTML, CSS y JavaScript puro. No usa una base de datos ni modifica información real.

## Cómo abrirlo

Abra `index.html` con un navegador. Para una experiencia más consistente también puede iniciar un servidor local desde esta carpeta.

## Funciones simuladas

- Navegación por todos los módulos.
- Diseño responsive para computadora y celular.
- Búsqueda y filtros de productos.
- Formularios de demostración.
- Cambio de cantidades y confirmación simulada de venta.
- Panel, alertas, historial, proveedores, categorías y usuarios.

Los datos existen únicamente en `app.js` y se restablecen al recargar la página. La implementación final se realizará con Flutter y Supabase.
